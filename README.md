System Requirements Specification
Elementary School Library Course Selection System

User Roles

General Users (Class Teachers):

Shall be able to log in to the system.
Shall be able to select one time slot for library usage per class.
Shall be able to view the course selection status of other users concurrently.

Administrators:
Shall be able to configure which time slots general users are permitted to modify.
Shall be able to add new general users.
Shall be able to modify user passwords.
Shall be able to delete course selections made by general users.

Functional Requirements:
The system shall restrict each class to a maximum of one selected time slot.
The system shall provide real-time visibility of course selection status across all logged-in users.
The system shall enforce administrator privileges for managing user accounts and time slot configurations.

Constraints:
Only one time slot may be assigned per class.
General users shall not exceed their assigned privileges.
